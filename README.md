# BABFT Blender Importer & Exporter

Blender tools for **Build A Boat For Treasure (BABFT)**.

Import .build files into Blender, edit your builds using Blender,
and export them back to BABFT.

BABFT → Blender → Edit → Export → BABFT

## ✨ Features

### 📥 Import

- Import .build files directly into Blender
- Load block positions, rotations and sizes
- Preserve original block colors
- Import transparent and invisible blocks
- Import mechanism blocks
- Import logic and connections
- Support Butter Hub, Luau and other scripts
- Duplicate block filtering
- Block limit up to **250,000 blocks**

### 📤 Export

- Export Blender scenes back to .build
- Preserve block position, rotation and size
- Export colors and materials
- Export transparency and collision settings
- Export mechanism logic
- Export connections and wiring
- Preserve MValues, Binds and connection IDs
- Replace block types automatically
- Global or local color/material modes
- Block limit up to **500,000 blocks**

## 🔄 Workflow
BABFT .build file - import - editoring in blender - export to babft .Build file
